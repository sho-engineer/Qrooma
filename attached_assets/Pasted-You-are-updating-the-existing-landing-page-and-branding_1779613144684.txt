# Product positioning to reflect

Clario is NOT just a “multi-AI debate tool.”
Clario is an **AI Decision Room** for **solo founders** and **product-minded builders**.

It helps users:
- clarify messy thinking
- compare options
- pressure-test assumptions
- structure decisions
- decide what to do now vs later
- turn decisions into a one-page memo
- hand off the result into execution tools

Core value:
**turn messy thinking into clear decisions and next actions**

Clario should be positioned as:
- not another chatbot
- not a PM tool
- not a meeting summary tool
- not a general AI workspace

Instead, Clario is:
- the layer between thinking and execution
- an AI Decision Room for founders who need to compare, pressure-test, and move forward

# Main problem to communicate

The key pain points are:

- thinking gets messy
- using only one AI often creates a narrow loop between “me + one AI”
- people explore options but still fail to decide clearly
- discussion does not convert into action
- decisions are not structured in a reusable way
- handoff to tools like ChatGPT, Claude, Manus, Replit, Claude Code, Cursor remains vague

The LP should communicate that Clario improves the **quality of decision-making**, not just the quantity of ideas.

# Visual design direction

This is very important.

The design should feel:
- monochrome
- typography-led
- clean
- sharp
- premium
- minimal
- editorial SaaS
- built for founders

It should NOT feel:
- colorful
- playful
- generic blue SaaS
- heavy with cards and icons
- startup-template-ish
- overdesigned

## Color palette
Use a monochrome palette only:
- background: #FFFFFF
- primary text: #111111
- secondary text: #525252
- border: #E7E7E7
- muted background: #F7F7F5
- button background: #111111
- button text: #FFFFFF

Avoid blue accents, gradients, colorful icons, glassmorphism, or decorative illustrations.

## Typography
Typography should carry the visual identity.

Use 2 fonts maximum.

Recommended:
- Heading font: Inter Tight or Manrope
- Body font: Inter

## Typography hierarchy
Use strong size contrast.

Recommended sizing:
- Hero title: 72–84px desktop / 42–48px mobile
- Hero subtitle: 20–24px desktop / 17–18px mobile
- Section titles: 36–44px desktop / 28–32px mobile
- Body text: 18px desktop / 16px mobile
- Small text: 13–14px
- Button text: 15–16px

## Layout feel
- generous whitespace
- strong visual rhythm
- fewer but stronger sections
- clean alignment
- controlled content width
- minimal icon usage
- simple but premium buttons
- subtle borders instead of decorative effects
