# Product positioning to reflect

Qrooma is NOT just a “multi-AI debate tool.”
Qrooma is an **AI Decision Room** for **solo founders** and **product-minded builders**.

It helps users:
- clarify messy thinking
- compare options
- pressure-test assumptions
- structure decisions
- decide what to do now vs later
- turn decisions into a one-page memo
- hand off the result into execution tools

The core value is:
**turn messy thinking into clear decisions and next actions**

Qrooma should be positioned as:
- not another chatbot
- not a PM tool
- not a meeting summary tool
- not a general AI workspace

Instead, Qrooma is:
**the layer between thinking and execution**
or
**an AI Decision Room for founders who need to compare, pressure-test, and move forward**

The main pain point is:

# Visual design direction

This is extremely important.

The design should feel:
- monochrome
- typography-led
- clean
- sharp
- premium
- minimal
- editorial SaaS
- built for founders

It should NOT feel:
- colorful
- playful
- generic blue SaaS
- heavy with cards and icons
- overdesigned
- startup-template-ish

## Color palette
Use a monochrome palette only:
- background: #FFFFFF
- primary text: #111111
- secondary text: #525252
- border: #E7E7E7
- muted background: #F7F7F5
- button background: #111111
- button text: #FFFFFF

Avoid blue accents, gradients, colorful icons, glassmorphism, or decorative illustrations.

## Typography
Typography should carry the visual identity.

Use 2 fonts maximum.

Recommended:
- Heading font: Inter Tight or Manrope
- Body font: Inter

If using Next.js fonts, use a reliable implementation.

## Typography hierarchy
Use strong size contrast.

Recommended sizing:
- Hero title: 72–84px desktop / 42–48px mobile
- Hero subtitle: 20–24px desktop / 17–18px mobile
- Section titles: 36–44px desktop / 28–32px mobile
- Body text: 18px desktop / 16px mobile
- Small text: 13–14px
- Button text: 15–16px

## Typography behavior
- Headlines should feel tight, confident, and slightly compressed
- Body text should feel spacious and readable
- Keep line lengths controlled
- Avoid dense paragraphs
- Use whitespace generously
- Use section labels / eyebrow text carefully and minimally

## Layout feel
- generous whitespace
- strong visual rhythm
- fewer but stronger sections
- clean alignment
- controlled content width
- high readability
- simple but premium buttons
- subtle borders instead of decorative effects
- minimal icon usage, ideally reduce icon dependence

The page should feel like a strong modern US founder tool, not a generic template.
