# 6. Feedback Board

Create a user-facing feedback board at:

/feedback

Purpose:
Collect user requests and use upvotes as a demand signal for roadmap prioritization.

Users should be able to:
- view feedback posts
- submit a feature request
- upvote a feature request
- remove their own upvote
- sort by most upvoted / newest
- see pinned posts at the top

Recommended tables:

feedback_posts:
- id
- slug
- user_id nullable
- title
- description
- status
- category
- upvote_count default 0
- is_pinned default false
- vote_threshold nullable
- threshold_action nullable
- cost_sensitive default false
- admin_priority_note nullable
- is_hidden default false
- is_roadmap_candidate default false
- created_at
- updated_at

feedback_votes:
- id
- feedback_post_id
- user_id nullable
- voter_email nullable
- created_at

Voting rule:
- one vote per user or email per feedback post
- if logged in, use user_id
- if not logged in, ask for email and prevent duplicate votes by email
- do not expose voter emails publicly
