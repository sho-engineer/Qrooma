期待結果：

- 認証成功後、/login に遷移する
- early_access_granted が保存される
- early_access_code が保存される
- early_access_granted_at が保存される
- early_access_expires_at が認証日時 + 14日で保存される

確認・修正ポイント：
- クーポンコードの大文字小文字、前後スペースをtrimして検証する
- Firestoreで検証している場合、対象クーポンが存在するか確認する
- 環境変数で検証している場合、EARLY_ACCESS_CODES に以下が含まれているか確認する

EARLY_ACCESS_CODES=ADJUDO-2W-BETA-7KQ9:early_access:14

- フロント側だけで検証している場合は、可能ならserver API経由に変更する
- ただしMVPとして最短修正が必要な場合、まずこのクーポンが確実に通る状態にする
- クーポン検証失敗時はconsole/server logに原因が分かるログを出す
- ユーザー画面にはraw errorを出さない

実装例：
- 入力値を trim()
- uppercase化して比較
- 有効コードと一致したら認証成功
- localStorageまたはcookieに以下を保存

early_access_granted=true
early_access_code=ADJUDO-2W-BETA-7KQ9
early_access_granted_at=<current ISO datetime>
early_access_expires_at=<current datetime + 14 days>

Firestore保存がある場合：
earlyAccessRedemptions に以下を保存

- code
- accessType: early_access
- grantedAt
- expiresAt
- locale
- timezone
- createdAt

成功時：
- 「認証しました。ログイン画面へ移動します。」を表示
- /login に遷移

失敗時：
- 「クーポンコードが正しくありません。」を表示

5. ISSUE-002 Waitlist登録失敗を修正
==================================================

不具合：
/waitlist で email/name/role を入力して送信すると、
「Something went wrong. Please try again.」で登録に失敗する。

期待結果：
- Waitlist登録が成功する
- 完了メッセージが表示される
- Firestore waitlist collection に保存される
- 未ログインユーザーでもWaitlist登録できる

確認・修正ポイント：
- Firestore write処理が正しいcollectionを参照しているか確認
- Firestore Security Rulesで未ログイン書き込みが許可されているか確認
- 入力field名と保存field名が一致しているか確認
- createdAt が正しく保存されるか確認
- name / role / comment がnullableまたはoptionalとして扱えるか確認
- 失敗時に内部ログへエラー内容を出す
- ユーザー画面にはraw errorを出さない

Firestore collection:
waitlist/{waitlistId}

保存項目：
- email
- name nullable
- role nullable
- comment nullable
- locale nullable
- timezone nullable
- createdAt

Firestore Rules要件：
- waitlist は未ログインでも create 可能
- read はAdminのみ
- update/delete はAdminのみ、または原則禁止

例：
match /waitlist/{docId} {
  allow create: if true;
  allow read, update, delete: if request.auth != null
    && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == "admin";
}

入力バリデーション：
- email必須
- email形式チェック
- name/role/commentは任意
- 不正メール形式の場合はFirestoreに保存しない

成功時文言：
日本語：
登録ありがとうございます。
準備ができ次第、ご案内します。

英語：
Thank you for joining the waitlist.
We’ll notify you when access is available.
