- Next actions
- Decision Memo

- Breaker

3. Breaker critiques assumptions and risks.
4. Operator synthesizes into a structured Decision Memo.
5. Final Conclusion / Decision Memo is saved and displayed.
6. UI language follows the user’s Settings language.
7. API key / BYOK / Free mode / model settings are not shown to users.
