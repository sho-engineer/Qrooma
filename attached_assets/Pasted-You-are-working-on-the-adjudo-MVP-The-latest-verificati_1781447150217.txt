P0-1: Fix completed + missing Decision Memo recovery UI

Current issue:
If room.lastRunStatus === “completed” but neither localStorage nor Firestore has a conclusion/memo, the UI shows “未確定 / Unresolved”.

This is misleading.

“Unresolved” should mean the discussion did not reach a decision.
But this case means:

* the room is marked completed
* the Decision Memo should exist
* but it could not be loaded or is missing

Expected behavior:
If status is completed but no structured memo and no rawText exists, show a dedicated recovery state.

Japanese:
Title:
Decision Memoが見つかりません

Body:
このルームは完了済みですが、保存されたDecision Memoを読み込めませんでした。再実行してください。

Button:
再実行

English:
Title:
Decision Memo not found

Body:
This room is marked as completed, but the saved Decision Memo could not be loaded. Please re-run this room.

Button:
Re-run

Important:
Do not show:

* 未確定
* Unresolved
* ラウンドを続ける
* 暫定結論を出す
* 条件を追加する

for this case.

Implementation guidance:

* Add a distinct state/prop to ConclusionCard, for example:
    * missingCompletedMemo
    * completedButMemoMissing
* RoomDetailPage should detect:
    * room.lastRunStatus === “completed” or runStatus === “completed”
    * no conclusion data
    * no rawText fallback
* Then render the dedicated missing memo UI.
* The only primary action should be Re-run.
